01 / CONTEXT

Entender qué exige operar servicios distribuidos, no solo dividir código.

DISCOVERY

Eureka + Config Server

Los servicios se descubren dinámicamente y comparten configuración centralizada para reducir dependencias rígidas.

MESSAGING

RabbitMQ ↔ Kafka

Perfiles alternativos permiten comparar brokers manteniendo el dominio desacoplado de la elección de mensajería.

OBSERVABILITY

Zipkin + ELK

Tracing distribuido y logs correlacionados por traceId/spanId permiten seguir una operación entre servicios.
